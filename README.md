# Stock Portfolio Tracker 📈

## CodeAlpha Python Programming Internship – Task 2

### 📌 About the Project
The Stock Portfolio Tracker is a simple Python-based project that calculates the total investment value of different stocks.

It allows users to enter stock names and quantities, calculates individual investment values, and displays the total investment.

### ✨ Features
- Displays available stocks and their prices.
- Takes stock names and quantities from the user.
- Checks stock availability.
- Calculates individual stock investment values.
- Calculates total portfolio investment.
- Saves the portfolio report in a text file (`portfolio.txt`).

### 🛠️ Technologies Used
- Python
- Dictionaries
- Loops
- If-Else Conditions
- User Input and Output
- Basic Arithmetic
- File Handling

### 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python stock_portfolio_tracker.py
```

5. Enter the number of stocks you want to buy.
6. Enter stock symbols and quantities.
7. View your total investment.
